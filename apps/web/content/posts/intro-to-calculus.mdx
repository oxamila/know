Calculus is the maths of **change** (derivatives) and **accumulation** (integrals). Everything below is interactive: **drag every slider** and **click the legend checkboxes** to hide or show curves.

- **Derivative** answers: *how fast is it changing right now?* (speed)
- **Integral** answers: *how much has piled up in total?* (distance)
- They are **opposites**, like multiplying and dividing.

## 1. Big picture: car dashboard

| You see | Calculus name | Meaning |
|---|---|---|
| Distance travelled | Function $f(x)$ | Where you are |
| Speedometer | Derivative $f'(x)$ | How fast it changes |
| Trip odometer | Integral $\int f(x)\,dx$ | Total accumulated |

Going **down** the table is *differentiating*. Going **up** is *integrating*.

## 2. Limits: getting closer and closer

A **limit** asks: what value does $f(x)$ approach as $x$ gets close to a number, even if we can't plug that number in?

$$
f(x)=\frac{x^2-1}{x-1}\quad\Rightarrow\quad \lim_{x\to 1} f(x)=2
$$

At $x=1$ we get $0/0$ (a hole), but for every other $x$ the function equals $x+1$, so it heads to $2$. Move the slider and watch the point slide toward the hole.

## 3. Three functions, three stories

Take the same starting function and see its **derivative** and **integral** side by side.

| | Function $f$ | Derivative $f'$ | Integral $F$ |
|---|---|---|---|
| Constant | $c$ | $0$ | $cx$ |
| Line | $x$ | $1$ | $\tfrac{x^2}{2}$ |
| Parabola | $x^2$ | $2x$ | $\tfrac{x^3}{3}$ |
| Cubic | $x^3$ | $3x^2$ | $\tfrac{x^4}{4}$ |
| Sine | $\sin x$ | $\cos x$ | $-\cos x$ |
| Exponential | $e^x$ | $e^x$ | $e^x$ |

**What each operation does to the graph**

- **Derivative** = the *slope* of $f$. Where $f$ rises, $f'$ is positive. Where $f$ has a peak or valley, $f'=0$.
- **Integral** = the *area* under $f$. Where $f$ is positive, $F$ climbs. Where $f$ is zero, $F$ is flat.

## 4. Derivatives: the slope at one point

### 4.1 From secant to tangent (the key idea)

A **secant** line joins two points on a curve. Shrink the gap $h$ between the points and the secant turns into the **tangent**, and its slope is the derivative.

$$
f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

Set $h$ big, then slide it toward $0$.

<MathGraph
  title="Secant becoming tangent for f(x) = x²  (point at x = a)"

  ]}
  functions={[
    { func: (x) => x * x, color: '#3b82f6', label: 'f(x) = x²' },
    { func: (x, p) => p.a * p.a + ((Math.pow(p.a + p.h, 2) - p.a * p.a) / p.h) * (x - p.a), color: '#f59e0b', label: 'secant (gap h)' },
    { func: (x, p) => p.a * p.a + 2 * p.a * (x - p.a), color: '#ef4444', label: 'tangent (slope 2a)' }

Secant slope here is $2a+h$. As $h\to 0$ it becomes $2a$, matching the rule $\frac{d}{dx}x^2=2x$.

Move $a$ and read the tangent. Steep up means big positive $f'$, flat means $0$, down means negative.

### 4.3 Rules (cheat sheet)

| Rule | Formula |
|---|---|
| Power | $\frac{d}{dx}x^n = n x^{n-1}$ |
| Constant multiple | $\frac{d}{dx}\big(c f\big) = c f'$ |
| Sum | $(f+g)' = f' + g'$ |
| Product | $(fg)' = f'g + fg'$ |
| Chain | $\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$ |

## 5. Integrals: area and accumulation

### 5.1 Area as rectangles (Riemann sum)

How do you measure the area under a curve? Slice it into $n$ thin rectangles, add them up, and let $n$ grow. More rectangles give a better answer.

$$
\int_a^b f(x)\,dx=\lim_{n\to\infty}\sum_{i=1}^{n} f(x_i)\,\Delta x
$$

  functions={[
    { func: (x) => x * x, color: '#3b82f6', label: 'f(x) = x²' },
    { func: (x, p) => { if (x < 0 || x > 3) return 0; const d = 3 / p.n; return Math.pow(Math.min(Math.floor(x / d), p.n - 1) * d, 2); }, color: '#8b5cf6', label: 'rectangles (left sums)', fill: true, fillOpacity: 0.3 }
  ]}
/>

At $n=4$ you underestimate (left rectangles sit under a rising curve). At $n=60$ the gap almost disappears. The exact area is $\int_0^3 x^2\,dx=\frac{3^3}{3}=9$.

### 5.3 Indefinite vs definite

| | Indefinite | Definite |
|---|---|---|
| Notation | $\int f(x)\,dx$ | $\int_a^b f(x)\,dx$ |
| Result | A **function** $F(x)+C$ | A **number** |
| Meaning | Family of anti-derivatives | Signed area from $a$ to $b$ |

The $+C$ appears because shifting a curve up or down does not change its slope.

## 6. The Fundamental Theorem of Calculus

This one idea ties everything together:

$$
\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\qquad\text{and}\qquad \int_a^b f(x)\,dx = F(b)-F(a)
$$

- **Part 1**: differentiate an integral and you get the original function back.
- **Part 2**: to find an area, find any anti-derivative $F$ and subtract the ends.

Example: $\int_1^3 2x\,dx = [x^2]_1^3 = 9-1 = 8$.

## 7. Worked examples

**Example 1: differentiate.** $f(x)=3x^4-5x^2+7$

$$
f'(x)=12x^3-10x
$$

**Example 2: chain rule.** $f(x)=\sin(x^2)$

$$
f'(x)=\cos(x^2)\cdot 2x
$$

**Example 3: integrate.** $\int (6x^2+4x-1)\,dx$

$$
=2x^3+2x^2-x+C
$$

**Example 4: definite integral.** $\int_0^{\pi}\sin x\,dx$

$$
=[-\cos x]_0^{\pi}=1-(-1)=2
$$

**Example 5: optimisation.** Fence a rectangle with $20\,\text{m}$ of wire. What width gives the largest area?

With width $w$, length is $10-w$, so area $A(w)=w(10-w)=10w-w^2$. Set $A'(w)=10-2w=0$, so $w=5$ (a $5\times5$ square), giving $A=25$.

**Example 6: real life.** A ball's height is $h(t)=20t-5t^2$ metres.

- Velocity is $h'(t)=20-10t$. At $t=2$ it is $0$ m/s (the top of the throw).
- Going backwards, integrating the velocity gives the height again.

## 8. Summary: derivative vs integral

| | Derivative | Integral |
|---|---|---|
| Question | How fast is it changing? | How much has built up? |
| Geometry | **Slope** of the tangent | **Area** under the curve |
| Direction | Breaks a quantity into change | Adds changes into a total |
| Power rule | $x^n \to n x^{n-1}$ | $x^n \to \frac{x^{n+1}}{n+1}$ |
| At a peak or valley of $f$ | $f'=0$ | $F$ has a slope of $f$, so it is flat only where $f=0$ |
| Real life | Speed from distance | Distance from speed |

> Derivatives and integrals are two views of one story: **change** and **accumulation**.
